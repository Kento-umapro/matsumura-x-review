# 松村僚 X｜中の人が書く版・確認用ページ

うまプロ COO 松村僚（[@Umapro_ryo](https://x.com/Umapro_ryo)）のX運用・第2案の確認用ページ。

- 公開URL: https://kento-umapro.github.io/matsumura-x-review/
- **コンセプト**: 本人が自分を語るのをやめ、近くで見てきた社員（中の人）が書く。
  オリエンタルラウンジ西山さん（@nyama_oriental）の「※主に秘書がツイートしています」と同じ構造
- **主力の型**: 一問一答（中の人が聞く → 松村が一言で切る → 中の人が受ける）
- 一次資料: 松村メッセージ vol.1〜415（本文＋コメント欄）。松村さんの発言は全て実在の言葉
- 判定（OK / 要修正）とメモは端末のlocalStorageに自動保存。「結果を送る」でまとめてコピー可
- 検索避け（noindex）済み
