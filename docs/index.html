秘書とBOSSの一問一喝

語り手を架空の秘書にして、全部を一問一答にしました。 秘書が質問して、BOSSが一言で斬って、秘書が受ける。それだけです。

@phads_kouhou（勝手に！さのなおし広報部）の「本人非公認で周りが面白がって発信する」構造と、 @sanonaoshi.everydaylifeの「知れば知るほど、この人が面白い」＝人物観察。この2つを合わせています。

トーンは面白おかしく、時々まじめに。だいたいは秘書が食い下がって斬られますが、 たまにBOSSが長めに答えて、秘書が黙る回を混ぜています。

2. 確認したいこと

色がついている1件だけ、決めていただく必要があります。残りは前回までに確定した内容です。

1【要確認】秘書というキャラクターを立てる形でよいか

架空の秘書がBOSSに質問して、一喝される。プロフィールに「※秘書は架空です」と明記します

西山さんの「主に秘書がツイートしています」と同じ構造ですが、うちは秘書自体が架空のキャラクターです。実在の秘書がいると誤解されないよう明記しています

2【要確認】BOSSのセリフを関西弁の会話体にしてよいか

「やる気なんかいらん。大事なのは覚悟や」など

元の言葉は全て松村メッセージ415本の中に実在しますが、会話として語尾を整えています。実際にその場でその質問をしたわけではありません

3【要確認】アカウントをどうするか

@Umapro_ryo を使うか、新規に立てるか

既存アカウントは認証バッジとフォロワー293人を引き継げますが、本人アカウントが秘書名義になるねじれが出ます

4【確定】表示名

→ 松村僚/一問一喝

「一問一答」のもじり。3回目の提案で決定しました

5【確定】マクドナルドの在籍期間

→ 16歳から31歳まで。15年

指示書の「12年」は誤りでした。全て修正済みです

6【確定】社内コメントの引用

→ OK

実名は伏せて「当時の方」「社員」などの表記にしています

7【確定】「ボス」の表記

→ BOSS

本文中すべて BOSS に統一済みです
